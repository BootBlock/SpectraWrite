# Contributing to SpectraWrite

Thank you for your interest in SpectraWrite. Contributions of ideas, bug reports and feature
requests are genuinely appreciated, and they shape what gets built next.

## Pull requests are never accepted

**SpectraWrite does not accept external pull requests.** A pull request opened by anyone who is not
a repository collaborator is closed automatically. This is not a judgement on the change, or on the
person who proposed it. SpectraWrite is developed in a private repository, and this public
repository carries only the issue tracker, the releases and the README, so a pull request here has
no source code to apply against.

## Open an issue instead

The best way to contribute is to
[open an issue](https://github.com/BootBlock/SpectraWrite/issues/new). A short summary of the change
you need is enough. It helps to include:

- What you want changed, added or fixed, in a line or two.
- What you expected to happen, and what happened instead, if you are reporting a bug.
- The SpectraWrite version you are running, which is shown on the **About** page.

A clear description of the problem is more useful than a patch, because it leaves room for the fix
to be designed to suit the rest of the application.

## Reporting a crash

SpectraWrite pre-fills a crash report for you when it detects an unhandled error. Please read the
pre-filled text before you submit it, and remove anything you would rather not publish, such as a
file path, a user name, or dictated text.
